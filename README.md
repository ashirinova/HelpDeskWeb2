# IT Help Desk — Texniki Dəstək Müraciətləri Sistemi (Laboratoriya İşi № 9)

Bu web tətbiq **ASP.NET Core MVC**, **Entity Framework Core** və **SQLite** verilənlər bazası istifadə edilərək hazırlanmışdır.

## Layihənin Funksiyaları
* **CRUD Əməliyyatları:** Yeni texniki dəstək müraciəti yaratmaq, siyahıya baxmaq, detalları görmək, redaktə etmək və silmək.
* **Validasiya:** Başlıq, təsvir və kateqoriya sahələrinin boş göndərilməsinin qarşısının alınması.
* **Əlavə Funksiyalar:**
  * Ana səhifədə sistemdəki ümumi müraciət sayının göstərilməsi.
  * Müraciətlərin kateqoriya, status və açar sözə (axtarış) görə filtrlənməsi.
  * `High` prioritetli müraciətlərin siyahıda qırmızı rənglə fərqləndirilməsi.

## Layihəni İşə Salmaq
1. Layihəni Visual Studio-da (`HelpDeskWeb2.slnx`) açın.
2. `F5` və ya `Ctrl + F5` düyməsini basaraq tətbiqi brauzerdə başladın.
